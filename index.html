Deterministic Architecture

How DeskFlow guards capital and ensures accurate execution across four distinct stages.

STAGE 01
Mandate Enforcement
Incoming agent intents are scrutinized against maximum notional allowances and venue permissions before any external tools activate.
STAGE 02
Venue Arbitrage
Queries live spot order depth alongside convert quotes to pinpoint the venue offering optimal execution quality and minimum slippage.
STAGE 03
Approval Intercept
DeskFlow halts routing until an exact token confirmation string is received, preventing conversational hallucinations from placing trades.
STAGE 04
Reconciliation
Reconciles actual balances and trade bills post execution, measuring true implementation shortfall in exact basis points.
Why Execution Clerks Matter

In autonomous finance, generation is simple but execution is lethal. Standard LLM agents frequently overcommit capital, misunderstand derivative leverage, or fall prey to hallucinated market prices.

DeskFlow serves as the deterministic risk officer. By constraining natural language models within an unbreachable sandbox, institutions can deploy autonomous intelligence without risking uncontrolled liquidation.

Mathematical Shortfall

Unlike naive bots that simply record the filled price, DeskFlow calculates execution shortfall relative to the original decision mid price:

Price Difference = Fill Price minus Decision Mid
Shortfall BPS = (Price Difference / Mid) * 10000

Exchange fees are kept in an isolated column, preventing fee conflation and ensuring pristine analytical auditability.

Frequently Asked Questions

Detailed answers regarding technical integration, safety boundaries, and design choices.

How does DeskFlow connect to the exchange? +
DeskFlow operates over the official Model Context Protocol endpoint provided by Binance. It uses standard HTTP streamable transport directly with the Agentic subaccount gateway without requiring third party intermediaries.
Can an agent override the mandate with prompt injection? +
No. The mandate is loaded at initialization and enforced at the code and logic boundary. Sizing caps, allowed assets, and prohibited derivative venues cannot be overridden by conversational instructions.
What happens if market data drops during order pricing? +
If telemetry is unavailable or returns an incomplete response, DeskFlow enforces a strict safety halt. It issues a Data Rejection code and terminates execution rather than guessing or fabricating numbers.
Why is human confirmation required? +
Autonomous agents must remain auditable. By requiring an explicit token confirmation match before dispatching orders, DeskFlow guarantees that human operators retain ultimate supervisory control over capital allocation.
